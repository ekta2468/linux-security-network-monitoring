 

# Linux System Security and Network Monitoring

## Project Overview
This project focuses on basic Linux system security and network monitoring using command-line tools.

## Tools Used
- Kali Linux
- Linux Terminal

## Tasks Performed
- Performed basic Linux network configuration and monitoring
- Checked IP address information using `ip addr`
- Checked network routing information using `ip route`
- Tested network connectivity using `ping`
- Monitored listening TCP/UDP ports using `ss -tuln`
- Verified the current Linux user using `whoami`

## Skills Demonstrated
- Linux command-line usage
- Basic network configuration
- Network troubleshooting
- Port monitoring
- Basic system security
